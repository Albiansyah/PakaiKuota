Bug layout di landing page (badge overlap, grid gak seragam, footer numpuk) kemungkinan bukan cuma di 1 halaman — audit dan perbaiki dari akar:

1. Cek root layout (layout.tsx / _app.tsx) — pastikan strukturnya:
   <div className="min-h-screen flex flex-col">
     <Header />
     <main className="flex-1">{children}</main>
     <Footer />
   </div>
   Ini mencegah footer numpuk ke konten di halaman manapun, termasuk halaman yang kontennya pendek.

2. Cek apakah ada komponen layout reusable (Container, Section, Grid) yang dipakai konsisten di semua halaman. Kalau tiap halaman hand-code class Tailwind sendiri-sendiri tanpa komponen shared, itu penyebab utama drift spacing antar halaman. Buat/perbaiki komponen ini SEKALI, lalu refactor semua halaman (landing, pricing, docs, dashboard/*, auth) untuk pakai komponen yang sama — jangan hardcode padding/gap manual di tiap halaman.

3. Setelah root layout & komponen shared diperbaiki, baru cek tiap halaman satu-satu untuk masalah spesifik yang tersisa (kayak badge position: absolute yang overlap di landing).

4. Screenshot SEMUA halaman (landing, pricing, docs, dashboard, login/register) setelah perbaikan, bandingkan konsistensi spacing-nya sebelum lapor selesai — jangan cuma cek landing page doang.
